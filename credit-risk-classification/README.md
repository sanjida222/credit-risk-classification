# Credit Risk Classification

A machine learning project focused on credit risk prediction and missing data handling.

## Techniques
- Mean Imputation
- Constant Imputation
- Drop Missing Values
- Iterative Imputation

## Machine Learning Models
- KNN
- Naive Bayes
- Logistic Regression
- Decision Tree
- Random Forest
- SVM
- Gradient Boosting
- XGBoost

## Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, XGBoost.

## How to Run
1. Clone this repository.
2. Install the required libraries.
3. Add the dataset.
4. Run the Jupyter Notebook.

## Purpose
To compare classification performance using different missing data handling techniques.
